This is a “Rhythm” game with 3 strikes displayed via the middle scoreboard text color; dodge the spikes and hit the orbs to the “beat”... (In an ideal world)
(By 'In an ideal world', I mean that the bpm isn't 100% accurate due to lag, which means that you can't set up a song or metronome to the game...)

You can change the bpm_input to increase/decrease bpm (Line 387) (no UI in the game for this unfortunately)

Black text = 0 strikes
Orange text = 1 strike
Red text = 2 strikes
3 strikes and you're out.

Controls are:
Move to top: E, J, Space.
Move to bottom: F, N, Space released.

Thus, control configurations are:
E/F (left handed) 
J/N (right handed)
J/F (two handed) (My favorite)
Space (either hand)

Reset: ` (button left of ‘1’ and above ‘tab’)
